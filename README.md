An elite, high-conversion single-page web application engineered for modern commercial fitness centers. Designed with a **Corporate Athletic Glow** dark-mode aesthetic, this platform bridges raw, high-contrast athletic visuals with intelligent conversion mechanics, real-time reactive engineering tools, and seamless dual-routing lead generation funnels.

---

## ⚡ Core Features

### 🎨 1. Premium Visual Design System

* **Corporate Athletic Glow UI:** A dark-mode canvas styled with deep carbon bases (`#0D0D0D`), clean matte card layers (`#161616`), and sharp, glowing neon orange/yellow action accents.
* **Fluid Micro-Interactions:** Interface items wrapped in responsive `framer-motion` layout states (hover transitions, structural scaling, and active button depths).
* **Anti-Conflict Layout:** A highly intentional navigation structure featuring optimized grid paddings to prevent responsive tab overlapping across mobile, tablet, and wide layout viewports.

### 🧮 2. The Bento Digital Fitness Hub (Reactive Calculators)

* **Instant BMI Engine:** A lightweight, single-page state engine parsing metric user height and weight inputs to compute real-time body mass indexes alongside color-coded classification banners.
* **Calorie TDEE Matrix:** Real-time client parameter indexing executing the **Mifflin-St Jeor Equation** to calculate Total Daily Energy Expenditure instantly upon changing parameters:

$$BMR = (10 \times \text{weight}) + (6.25 \times \text{height}) - (5 \times \text{age}) + 5$$

### 📈 3. Conversion Mechanics & Client Lead Generation

* **Dual-Routing Inquiry System:** An advanced client contact interface built to instantly parse user input states and forward queries through a clean selection layout:

  * **Email Routing Engine:** Immediate structural standard mail composition strings.
  * **WhatsApp API Gateway:** Dynamic custom string parsing forwarding message data directly to gym operators: `https://wa.me/917042249976?text=...`
* **Right-Side Utility Dock:** Integrated direct call CTA triggers (`+91 70422 49976`) alongside high-visibility interactive inline social arrays (Instagram, Facebook, Email).

## 🛠️ Tech Stack & Architecture

* **Framework Core:** React (SPA Architecture, Component Reusability)

* **Styling:** Tailwind CSS (Custom Dark Theme Extension Configs)
* **Animation System:** Framer Motion (State-Driven Component Micro-interactions)
* **Icon Ecosystem:** Lucide React / FontAwesome React Icons

## 🚀 Getting Started Locally

Follow these quick steps to clone, install dependencies, and spin up the production development environment:

### 1. Clone the repository:

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/ironcore-fitness-gym.git
cd ironcore-fitness-gym
```

### 2. Install Node Dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3. Launch the local development server:

```bash
npm run dev
```

### 4. Production Build Generation:

```bash
npm run build
# This generates your optimized production static assets inside the /dist directory
```
